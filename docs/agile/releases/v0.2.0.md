## 5. 已知限制（随后续版本解决）

| 限制 | 影响 | 解决故事 |
|---|---|---|
| 真实链路验收（记忆写入→召回、双模型语气对比）依赖 API Key | 自动化只覆盖无 Key 部分，真实体验由 PO 演示确认 | PO 演示 + VG-107（本地化后可全自动） |
| 记忆依赖 OpenAI embedding | 无 OpenAI Key 时记忆不可用（对话与会话恢复不受影响） | VG-107 |
| 会话快照为全量 JSON（每轮整份保存） | 超长会话磁盘占用线性增长 | 远期优化（增量快照），暂不登记故事 |
| Windows 下长会话/控制台交互未做大规模实测 | 已知 Windows REPL 退出组合（Ctrl+C/Ctrl+Z+Enter）行为差异 | 随 M4 桌面化消除 |
