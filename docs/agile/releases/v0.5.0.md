## 4. PO 演示指引

```bash
uv sync && uv run vibegoing ui     # 桌面窗口打开（或 --no-window 用浏览器）
# 1) 伙伴页 → ＋新建伙伴：五步向导（第 3 步可 "Soul 一键生成 ✨"，需 .env 配 Key）
# 2) 聊天页 → 选伙伴 → 发消息（打字机输出；CLI 伙伴危险指令会出现放行审批条）
# 3) 任务台账 → 输入协作任务 → 运行 → 轮询状态 → 点开看阶段产物
# 4) 执行体页 → 健康检查（本机已实测检出 claude）；设置页 → 版本与隐私说明
```

## 5. 已知限制（ADR-0008 声明）

| 限制 | 影响 | 解决 |
|---|---|---|
| 无原生安装包/托盘 | 启动需 `vibegoing ui` 命令 | VG-405（PyInstaller 体积实测后再定 Tauri） |
| 聊天为整段返回 + 前端打字机 | 长回复感知延迟 | SSE 流式（VG-405 关联） |
| 前端无自动化测试（无构建链取舍） | 界面回归靠人工/API 层保障 | API 层 TestClient 全覆盖兜底；引入 Playwright 列远期 |
| 真实 LLM/记忆链路需 Key | 机制层全自动验证 | PO 演示 |
