## 5. 已知限制

| 限制 | 影响 | 解决 |
|---|---|---|
| Kimi Code 使用 text 输出（stream-json 契约未稳定） | 流式粒度为"行"而非 token | 官方契约稳定后升级，改动集中在 parse_line |
| dsh/zcode 输出含会话噪音（进度/日志行） | 最终答案与过程行混排 | 真实输出样本回来后加过滤规则（VG-306 关联） |
| `--auto` 模式下 Kimi 内部自动放行 | 内层权限弱化 | 外层 PermissionGate（目录白名单+危险模式）仍为硬前置，红线不降级 |
