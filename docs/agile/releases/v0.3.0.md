## 2. M2 验收标准逐条核对

验收标准（PLAN.md §4 M2）：*终端执行 `vibegoing crew run "调研 X 并写摘要"`，
自动完成 调研（伙伴A）→ 复核（伙伴B）→ 汇总交付，阶段进展实时可见；
中间产物与最终结论均落任务台账。*

| 验收要素 | 结果 | 证据 |
|---|---|---|
| 一条命令自动完成 调研→复核→汇总 | ✅ | `test_crew_run_review_out_of_box`：`crew run` 开箱跑通三阶段（产出/复核/汇总），伙伴不足自动补齐复核者 |
| 伙伴 A ≠ 伙伴 B（不同伙伴协作） | ✅ | 同上测试断言 stages 依次为 produce(researcher 路由方)→review(bob)→finalize；`test_review_pipeline_three_stages_in_ledger` |
| 阶段进展实时可见 | ✅ | 管线 announce 逐阶段输出（`test_review_pipeline_three_stages_in_ledger` 断言"阶段 1/3 产出/阶段 2/3 复核/完成"）；CLI 最终打印"最终结论" |
| 中间产物与最终结论落台账 | ✅ | `crew_tasks/crew_stages` SQLite：`test_task_lifecycle_with_stages`、`test_crew_status_and_list`（status 展示全部阶段产物） |
| 能力路由（未指名派对伙伴） | ✅ | `test_rank_by_capability_match`、`test_pick_pair_returns_two_distinct`；点名优先 `test_rank_name_mention_beats_capability` |
| 层级派活（管理者拆解分派） | ✅ | `test_crew_run_hierarchy`、`test_hierarchy_pipeline_executes_plan_with_accumulated_context`（计划校验/单步兜底 `test_manager_plan_parses_and_validates`） |
| 交接协议有文档 | ✅ | `HandoffPacket` 协议 v1（handoff.py docstring + ADR-0006）；跨阶段上下文累积有测试断言 |
| 真实模型体验 | ⏳ PO 演示 | 自动化全用替身 LLM（无 Key 可验机制）；真实体验命令：`uv run vibegoing crew run "调研 X 并写摘要"` |
