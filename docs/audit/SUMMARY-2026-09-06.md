## 历史技术债（P2，不阻断发布）

1. **teammate ↔ runtimes 延迟导入环未在 ADR 记录**：双方函数内互调是有意设计（避免加载期环），但 ADR-0002/0007 未声明该模式；建议在 ADR-0007 补一段「延迟导入约定」，防止后人误当 bug "修复"。
2. **`runtimes/executor.py` 顶层依赖 `collab.ledger`**：执行层反向依赖协作层的台账模块。台账本质是共享基础设施，建议后续上移（如 `vibegoing/ledger.py`），使 runtimes 不依赖 collab。
3. **`collab/pipeline.py` 顶层依赖 `teammate._default_llm`**：LLM 工厂是共享工具，建议抽到独立模块（如 `llm_utils.py`），消除 collab→teammate 顶边。
4. **CrewAI 触点扩散**：ADR-0001 声称"CrewAI 调用收拢在 teammate.py"，实际顶层 crewai 导入已分布 3 处（teammate.py、runtimes/base.py、collab/pipeline.py，后两处为类型导入）。不算违规，但框架升级检查面变宽——建议维护一份「CrewAI 触点清单」作为升级 checklist。
